# صدقة جارية — أحمد جمال

موقع عربي RTL متجاوب بهوية زمردية وذهبية، قابل للنشر على GitHub Pages كتطبيق ويب تقدمي (PWA).

## التشغيل والنشر
1. ارفع **محتويات هذا المجلد** إلى مستودع GitHub (يجب أن يكون `index.html` في الجذر).
2. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)`.
3. افتح رابط GitHub Pages عبر HTTPS. السماح بالموقع الجغرافي وخصائص PWA يحتاجان HTTPS أو localhost.
4. ثبّت التطبيق من قائمة المتصفح إذا أتاح المتصفح ذلك.

## ما يعمل في النسخة الحالية
- واجهة عربية RTL، تصميم متجاوب، وضع ليلي/نهاري.
- مصحف الصفحات: يعرض صفحات QPC2 الحقيقية ذات حدود الأسطر المحددة من مجموعة `zonetecde/mushaf-layout` (604 صفحة، حفص عن عاصم) ويحمّل خط الصفحة المطابق `pNNN.woff2` من المصدر نفسه؛ لا يعيد توزيع نص الآيات تلقائيًا. يدعم التنقل، السحب، البحث، فهرس السور، حفظ آخر صفحة، وضع علامة للصفحة، نسخ/مشاركة/حفظ الآية. التفسير يُطلب عند اختيار الخيار 4 من مصدر `ar.muyassar`؛ إذا لم يقدمه المصدر تظهر رسالة عدم التوفر.
- استماع إلى السورة كاملة من ملفات كل قارئ على حدة، مع التحقق من فهرس MP3Quran واختيار رواية حفص فقط، وحفظ موضع التشغيل وتكرار السورة أو الآية والتنقل بين السور. القارئ الذي لا يتوفر له ملف موثوق يظهر كخيار غير متاح ولا يستبدل بصوت آخر.
- قوائم بداية من الأحاديث والأدعية والأذكار مع مراجع مرفقة، تصنيف، بحث/تصفية، نسخ ومفضلة، وعدادات للأذكار.
- سبحة مع حفظ العدد وسجل الجلسات وهدف اختياري.
- حساب زاوية القبلة باستخدام الموقع الجغرافي بعد موافقة المستخدم، مع توضيح حدود البوصلة.
- تخزين الإعدادات والمفضلة والتقدم محليًا. Service Worker يخزن ملفات التطبيق وصفحات QPC2 والخطوط التي تم تحميلها بنجاح؛ الصوت لا يُحمّل تلقائيًا كاملًا دون اتصال.

## حدود معلنة — لا تعتبرها ميزات مكتملة
- مكتبة الأحاديث والأدعية والأذكار هنا **بداية منتقاة وليست مكتبة كبيرة شاملة**. ينبغي مراجعة النصوص والمراجع ودرجات الحديث مع مختص قبل اعتمادها للنشر العام.
- لا توجد بعد تنبيهات مجدولة للأذكار، أو إعدادات متقدمة شاملة، أو إدارة مزامنة عبر أجهزة. المتصفح قد يقيّد الإشعارات في الصفحات الثابتة.
- أسماء القراء ليست مضمونة جميعها لدى API. الكود يستخدم فهرس القراء من MP3Quran API v3 ويختار مصحف حفص لكل قارئ، ثم يبني رابط السورة من `server` ورقم السورة ذي 3 خانات، ولا يعرض إلا ما يرجع به المصدر فعلًا. لا تُخترع روابط للمعرفات الغائبة.
- مستشعر البوصلة غير موحد بين الهواتف. عند توفر حدث اتجاه الجهاز يُستخدم لتدوير المؤشر، وإلا يُعرض الاتجاه بالنسبة للشمال دون ادعاء وجود بوصلة معايرة.
- خطوط وصفحات QPC2 والصوت والبحث والتفسير تحتاج اتصالًا أول مرة، باستثناء ما سبق تحميله ونجح تخزينه محليًا. فهرس MP3Quran قد لا يحتوي كل الأسماء المطلوبة؛ أي قارئ غير موجود أو بلا رواية حفص يظهر غير متاح بدل توجيهه لصوت قارئ آخر.

## مصادر البيانات
- بيانات الآيات والتفسير: [AlQuran Cloud API](https://alquran.cloud/api).
- فهرس القراء وروابط التسجيلات: [MP3Quran API](https://www.mp3quran.net/ar/api).
- تخطيط صفحات المصحف وخطوط QPC2: [Mushaf Layout Dataset](https://github.com/zonetecde/mushaf-layout) — مجموعة لكل صفحة وخطها المطابق. بيانات المصدر منشورة لكل صفحة، ويجب مراجعة المصدر وحقوق الخطوط قبل إعادة توزيع الأصول.
- المراجع المكتوبة بجانب الأحاديث والأدعية والأذكار هي بيانات تعريفية ضمن ملفات `data/`؛ لا يوجد اتصال بقاعدة بيانات حديث خارجية في هذا الإصدار.

## ملفات المشروع
- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم.
- `app.js`: التفاعلات والاتصال بالمصادر.
- `data/*.json`: محتوى مختار مع المراجع.
- `assets/logo.svg`: الشعار الأصلي بصيغة SVG.
- `manifest.webmanifest` و`sw.js`: إعدادات PWA والتخزين المؤقت.

## ملاحظة
هذا إصدار أول قابل للتجربة والنشر كواجهة ثابتة، وليس شهادة تدقيق شرعي أو اختبار توافق شامل لكل جهاز ومتصفح. راجع المصادر والمحتوى قبل نشره باعتباره مرجعًا دينيًا.
